實驗模擬

Skill 1

Earth1B_Laboratory safety_(本生燈點火)

按正確次序：關氣孔 → 點火柴 → 開煤氣 → 開氣孔。做錯會即時見到危險提示。

開始練習 → Skill 2

Earth3B_Chemical tests and electrolysis_(氣體製備同收集)

氨氣、二氧化碳、裂解：揀試管角度同收集方法。錯機會見到倒流、炸裂或者氣體流失。

開始練習 → Skill 3

Earth3B_Chemical tests and electrolysis_(防止倒吸)

排水法停火：只提起水槽端尖端離水，試管端保持接駁；次序錯會見倒吸炸裂。

開始練習 → Skill 4

Earth2A_Matters_(物質微觀分類)

睇粒子動畫分辨單原子元素、分子元素、化合物、純物質同混合物。說明文字可以隱藏。
